CONFIGURATION MANAGEMENT POLICY
Organization: ASJ Realty
Control: 3.4.9 - User-Installed Software Control
Version: 1.2  |  Effective: 2026-01-15
Owner: Sandra Okonkwo, IT Director  |  Approved: Anthony James, Office Manager

1. PURPOSE
This policy controls and monitors user-installed software on ASJ Realty information systems, per NIST SP 800-171 Rev. 2 control 3.4.9.

2. SCOPE
All ASJ Realty CUI endpoints and systems.

3. REQUIREMENTS
a. Standard users do not have local administrator rights on CUI endpoints.
b. All software must be installed by Sandra Okonkwo from the approved software list.
c. Sandra Okonkwo scans endpoints monthly for unapproved or newly installed software.
d. Unapproved software is removed within 24 hours of detection.
e. Personnel are prohibited from installing personal software on ASJ Realty systems.

4. RESPONSIBILITY
Sandra Okonkwo, IT Director, controls software installation and conducts monthly software audits.

5. ENFORCEMENT
Personnel who install unauthorized software receive disciplinary action.

Signed: Anthony James, Office Manager  |  ASJ Realty  |  2026-01-15
