IDENTIFICATION AND AUTHENTICATION POLICY
Organization: Money Straight Talk LLC
Control: 3.5.2 - User Authentication
Version: 1.2  |  Effective: 2026-01-15
Owner: Terrell Banks, Systems Admin  |  Approved: Camille Odom, CEO

1. PURPOSE
This policy requires Money Straight Talk LLC to authenticate the identities of users, processes, and devices before granting access to CUI systems, per NIST SP 800-171 Rev. 2 control 3.5.2.

2. SCOPE
All access to Money Straight Talk LLC CUI systems and resources.

3. REQUIREMENTS
a. All CUI system access requires successful authentication before access is granted.
b. Authentication is enforced via Azure AD with MFA for all accounts.
c. Passwords must meet complexity requirements as defined in policy 3.5.7.
d. Device authentication uses certificate-based enrollment via Intune.
e. Failed authentication attempts are logged and monitored.

4. RESPONSIBILITY
Terrell Banks, Systems Admin, configures and maintains authentication controls.

5. ENFORCEMENT
Unauthenticated access to CUI systems is technically blocked and generates security alerts.

Signed: Camille Odom, CEO  |  Money Straight Talk LLC  |  2026-01-15
