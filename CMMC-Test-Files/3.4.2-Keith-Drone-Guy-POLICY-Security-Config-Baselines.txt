CONFIGURATION MANAGEMENT POLICY
Organization: Keith the Drone Guy LLC
Control: 3.4.2 - Security Configuration Baselines
Version: 1.2  |  Effective: 2026-01-15
Owner: Keith Merritt, Owner-Operator  |  Approved: Keith Merritt, Owner-Operator

1. PURPOSE
This policy requires Keith the Drone Guy LLC to establish and enforce security configuration settings for information technology products, per NIST SP 800-171 Rev. 2 control 3.4.2.

2. SCOPE
All Keith the Drone Guy LLC hardware and software in the CUI environment.

3. REQUIREMENTS
a. Security configuration baselines are derived from CIS Benchmarks or DISA STIGs.
b. Baselines are applied to all CUI endpoints via Intune configuration profiles.
c. Endpoints that drift from baseline are flagged as non-compliant.
d. Keith Merritt remediates baseline deviations within 72 hours.
e. Baselines are reviewed and updated annually or after major OS releases.

4. RESPONSIBILITY
Keith Merritt, Owner-Operator, creates, applies, and maintains security configuration baselines.

5. ENFORCEMENT
Non-compliant endpoints are blocked from CUI access until remediated.

Signed: Keith Merritt, Owner-Operator  |  Keith the Drone Guy LLC  |  2026-01-15
