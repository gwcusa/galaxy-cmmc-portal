CONFIGURATION MANAGEMENT POLICY
Organization: Money Straight Talk LLC
Control: 3.4.5 - Access Restrictions for Configuration Changes
Version: 1.2  |  Effective: 2026-01-15
Owner: Terrell Banks, Systems Admin  |  Approved: Camille Odom, CEO

1. PURPOSE
This policy defines and enforces access restrictions associated with Money Straight Talk LLC configuration changes, per NIST SP 800-171 Rev. 2 control 3.4.5.

2. SCOPE
All Money Straight Talk LLC CUI systems and their configuration management functions.

3. REQUIREMENTS
a. Only Terrell Banks is authorized to implement configuration changes on CUI systems.
b. Physical access to server rooms and network equipment requires key card authorization.
c. Remote configuration changes require VPN and MFA authentication.
d. Configuration management tools are accessible only to Terrell Banks.
e. Attempts by unauthorized users to make configuration changes are detected and alerted.

4. RESPONSIBILITY
Terrell Banks, Systems Admin, implements and enforces access restrictions for system configuration.

5. ENFORCEMENT
Unauthorized configuration changes are treated as security incidents.

Signed: Camille Odom, CEO  |  Money Straight Talk LLC  |  2026-01-15
