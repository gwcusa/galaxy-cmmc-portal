CONFIGURATION MANAGEMENT POLICY
Organization: Blue Ridge Technology Solutions LLC
Control: 3.4.4 - Security Impact Analysis
Version: 1.2  |  Effective: 2026-01-15
Owner: Nathan Cruz, IT Manager  |  Approved: Victor Osei, Director of Operations

1. PURPOSE
This policy requires Blue Ridge Technology Solutions LLC to analyze the security impact of changes prior to implementation, per NIST SP 800-171 Rev. 2 control 3.4.4.

2. SCOPE
All planned changes to Blue Ridge Technology Solutions LLC CUI systems.

3. REQUIREMENTS
a. Each change request includes a security impact assessment section.
b. Nathan Cruz assesses potential security impacts before approving any change.
c. High-risk changes require additional review and testing.
d. Security impacts that cannot be mitigated result in change rejection.
e. Security impact assessments are documented and retained with change records.

4. RESPONSIBILITY
Nathan Cruz, IT Manager, performs security impact assessments. Victor Osei reviews high-risk assessments.

5. ENFORCEMENT
Changes submitted without a security impact assessment are automatically rejected.

Signed: Victor Osei, Director of Operations  |  Blue Ridge Technology Solutions LLC  |  2026-01-15
