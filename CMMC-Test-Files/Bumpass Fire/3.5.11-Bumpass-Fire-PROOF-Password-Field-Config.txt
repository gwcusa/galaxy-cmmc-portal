IDENTIFICATION AND AUTHENTICATION IMPLEMENTATION EVIDENCE
Organization: Bumpass Fire & Rescue
Control: 3.5.11 - Authentication Feedback Obscuring
Prepared By: Mike Sadler, IT Coordinator  |  Date: 2026-07-10

1. SUMMARY
Evidence that Bumpass Fire & Rescue obscures authentication feedback on all CUI system login interfaces.

2. AUTHENTICATION INTERFACE REVIEW
Date: 2026-06-20  |  Reviewer: Mike Sadler
Interfaces reviewed: Windows 11 Login, Azure AD / M365 Web Login, VPN Login, SharePoint

Windows 11 Login (BFR-WS-001):
- Password field: Masked (dots) by default
- Error message: "The user name or password is incorrect" (generic - does not specify which)
- Credential Manager: Not saved for CUI resources
Result: PASS

Azure AD Web Login (login.microsoftonline.com):
- Password field: Masked with asterisks, optional "Show password" toggle
- Error: "Your account or password is incorrect" (generic)
Result: PASS

VPN Login (GlobalProtect):
- Password field: Masked
- Error: "Authentication failed" (generic)
Result: PASS

3. PASSWORD FIELD CONFIGURATION (GPO)
GPO: PasswordFieldMask-Bumpass Fire & Rescue
- DisablePasswordReveal: 1 (hides "show password" eye icon on Windows login)
Applied to: All Bumpass Fire & Rescue Windows endpoints

4. BROWSER SETTINGS
Microsoft Edge policy: PasswordManagerEnabled = False (no password saving on CUI endpoints)
This prevents autofill from potentially exposing credentials.

5. CONCLUSION
All Bumpass Fire & Rescue authentication interfaces obscure password feedback and use generic error messages per control 3.5.11.
