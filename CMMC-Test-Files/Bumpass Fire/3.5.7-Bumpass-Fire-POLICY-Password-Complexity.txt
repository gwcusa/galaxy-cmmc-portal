IDENTIFICATION AND AUTHENTICATION POLICY
Organization: Bumpass Fire & Rescue
Control: 3.5.7 - Password Complexity and Reuse
Version: 1.2  |  Effective: 2026-01-15
Owner: Mike Sadler, IT Coordinator  |  Approved: Randy Bowles, Fire Chief

1. PURPOSE
This policy establishes Bumpass Fire & Rescue's password complexity and change requirements, per NIST SP 800-171 Rev. 2 control 3.5.7.

2. SCOPE
All Bumpass Fire & Rescue user accounts with access to CUI systems.

3. REQUIREMENTS
a. Minimum password length: 14 characters.
b. Passwords must include uppercase, lowercase, numbers, and special characters.
c. Passwords may not contain the user's account name or display name.
d. Passwords expire every 365 days (or never if MFA is required).
e. Users may not reuse their previous 24 passwords.
f. Password complexity is enforced via Azure AD Password Protection.

4. RESPONSIBILITY
Mike Sadler, IT Coordinator, configures and enforces password policy via Azure AD.

5. ENFORCEMENT
Non-compliant password attempts are automatically rejected.

Signed: Randy Bowles, Fire Chief  |  Bumpass Fire & Rescue  |  2026-01-15
