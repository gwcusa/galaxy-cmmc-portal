1. SUMMARY
Evidence that Bumpass Fire & Rescue protects audit logs from unauthorized modification or deletion.

2. LOG PROTECTION CONTROLS
Platform: Microsoft Sentinel + Log Analytics (tenant: bumpassfire.org)

Immutability: Log Analytics workspace configured with 90-day immutability lock.
Records cannot be deleted or modified by any user during retention period.

Access Control (RBAC):
- Log Analytics Reader: Randy Bowles (read-only - for review/audit)
- Log Analytics Contributor: Mike Sadler (query and configure, cannot delete logs)
- Log Analytics Data Purge: Not assigned to any Bumpass Fire & Rescue user
- Owner: Azure Subscription admin (break-glass account, MFA + PAM required)

Backup: Logs exported to Azure Blob Storage (GRS redundancy)
Blob container: cui-logs-backup-bumpassfire.org | Access: Mike Sadler only | Soft delete: 30 days

3. ACCESS AUDIT
Log access itself is audited via Azure Activity Log.
Azure Activity Log: Immutable, managed by Microsoft.

Bumpass Fire & Rescue protects audit logs via RBAC, immutable storage, and geo-redundant backup per control 3.3.8.
