SYSTEM AND COMMUNICATIONS PROTECTION POLICY
Organization: Money Straight Talk LLC
Control: 3.13.3 - Security Function Separation
Version: 1.2  |  Effective: 2026-01-15
Owner: Terrell Banks, Systems Admin  |  Approved: Camille Odom, CEO

1. PURPOSE
This policy requires Money Straight Talk LLC to separate user functionality from information system management functionality, per NIST SP 800-171 Rev. 2 control 3.13.3.

2. SCOPE
All Money Straight Talk LLC CUI systems and the users who access them.

3. REQUIREMENTS
a. System management functions (admin consoles, configuration tools) are accessible only to Terrell Banks.
b. Standard users access only user-facing applications and cannot reach management interfaces.
c. Administrative and user functions run in separate sessions and accounts.
d. Management interfaces are not exposed on the same network segment as user desktops.
e. Separation is verified during quarterly access reviews.

4. RESPONSIBILITY
Terrell Banks, Systems Admin, implements and verifies security function separation.

5. ENFORCEMENT
Standard user accounts with management function access are immediately remediated.

Signed: Camille Odom, CEO  |  Money Straight Talk LLC  |  2026-01-15
