IDENTIFICATION AND AUTHENTICATION POLICY
Organization: Money Straight Talk LLC
Control: 3.5.7 - Password Complexity and Reuse
Version: 1.2  |  Effective: 2026-01-15
Owner: Terrell Banks, Systems Admin  |  Approved: Camille Odom, CEO

1. PURPOSE
This policy establishes Money Straight Talk LLC's password complexity and change requirements, per NIST SP 800-171 Rev. 2 control 3.5.7.

2. SCOPE
All Money Straight Talk LLC user accounts with access to CUI systems.

3. REQUIREMENTS
a. Minimum password length: 14 characters.
b. Passwords must include uppercase, lowercase, numbers, and special characters.
c. Passwords may not contain the user's account name or display name.
d. Passwords expire every 365 days (or never if MFA is required).
e. Users may not reuse their previous 24 passwords.
f. Password complexity is enforced via Azure AD Password Protection.

4. RESPONSIBILITY
Terrell Banks, Systems Admin, configures and enforces password policy via Azure AD.

5. ENFORCEMENT
Non-compliant password attempts are automatically rejected.

Signed: Camille Odom, CEO  |  Money Straight Talk LLC  |  2026-01-15
