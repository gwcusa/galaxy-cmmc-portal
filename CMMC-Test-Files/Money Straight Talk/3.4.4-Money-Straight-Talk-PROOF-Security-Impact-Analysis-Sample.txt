CHG-2026-061 - Security Impact Analysis
-------------------------------------------------
Change:       Enable Windows Defender Credential Guard on
              all MST workstations
Date:         June 15, 2026
Analyzed By:  Terrell Banks

Affected Systems: MST-WS-001 through MST-WS-004
Affected Controls: IA (credential protection), SI (malware)

Security Impact Assessment:
  Positive Impacts:
    - Prevents credential theft (Pass-the-Hash attacks)
    - Isolates LSASS in virtualization-based security container
    - Reduces risk from credential-dumping malware
  Potential Negative Impacts:
    - Some legacy authentication protocols may fail
      (Kerberos unconstrained delegation - not used at MST)
    - Requires TPM 2.0 (all MST devices have TPM 2.0 - verified)
    - Performance overhead: minimal (<2% per Microsoft docs)
  Rollback Plan: Disable via GPO if critical issues arise
  New Attack Surface Introduced: NONE
  Recommendation: APPROVE

Approval: Camille Odom - June 15, 2026 - APPROVED
Implemented: June 16, 2026 - SUCCESS
