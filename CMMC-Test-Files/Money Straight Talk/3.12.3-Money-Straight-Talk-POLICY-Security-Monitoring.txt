SECURITY ASSESSMENT POLICY
Organization: Money Straight Talk LLC
Control: 3.12.3 - Security Control Monitoring
Version: 1.2  |  Effective: 2026-01-15
Owner: Terrell Banks, Systems Admin  |  Approved: Camille Odom, CEO

1. PURPOSE
This policy requires Money Straight Talk LLC to monitor security controls on an ongoing basis to ensure their continued effectiveness, per NIST SP 800-171 Rev. 2 control 3.12.3.

2. SCOPE
All security controls implemented in Money Straight Talk LLC CUI systems.

3. REQUIREMENTS
a. Security controls are continuously monitored through automated tools and periodic reviews.
b. Microsoft Sentinel provides continuous monitoring of security events.
c. Terrell Banks conducts weekly security dashboard reviews.
d. Monthly security posture reports are provided to Camille Odom.
e. Control effectiveness degradation triggers immediate review and remediation.

4. RESPONSIBILITY
Terrell Banks, Systems Admin, monitors and reports on security control effectiveness continuously.

5. ENFORCEMENT
Degraded security controls are treated as priority incidents requiring same-day remediation.

Signed: Camille Odom, CEO  |  Money Straight Talk LLC  |  2026-01-15
