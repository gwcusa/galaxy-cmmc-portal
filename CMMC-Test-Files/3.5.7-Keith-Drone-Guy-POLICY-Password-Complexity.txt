1. PURPOSE
Strong passwords are a critical defense for protecting Keith
the Drone Guy LLC systems, including federal contract data,
drone flight plans, and CUI imagery from USDA and Army Corps
of Engineers contracts.

2. PASSWORD REQUIREMENTS

2.1 Complexity Requirements
All passwords for company systems must meet:
  - Minimum length: 14 characters
  - Must include at least ONE of each:
      * Uppercase letter (A-Z)
      * Lowercase letter (a-z)
      * Number (0-9)
      * Special character (! @ # $ % ^ & * etc.)
  - Must NOT contain the user's name or username
  - Must NOT contain the word "password" or common words
  - Must NOT be a previously used password (last 12 enforced)

2.2 Password Change
  - Passwords must be changed at least every 180 days
  - Users are prompted 14 days before expiration
  - Temporary passwords (set by admin) must be changed
    at first login — no exceptions

2.3 Password Reuse
  - The last 12 passwords may not be reused
  - System enforces this automatically via Microsoft 365
    and Azure AD password protection

3. PASSWORD STORAGE
  - Passwords are NEVER stored in plain text
  - All passwords are stored as salted hashes (bcrypt)
  - Passwords must NEVER be written down or shared
  - The company-approved password manager (Bitwarden Teams)
    is the only approved method for storing passwords

4. ACCOUNT LOCKOUT
  - Accounts lock after 5 consecutive failed login attempts
  - Lockout duration: 30 minutes (auto-unlock)
  - Permanent lockout is possible after 15 failed attempts
    within 1 hour — requires IT reset

5. MULTI-FACTOR AUTHENTICATION
MFA is required in addition to passwords for all accounts.
See POL-IA-002 for full MFA requirements.

6. PROHIBITED PRACTICES
  - Sharing passwords with anyone, including supervisors
  - Using the same password across multiple systems
  - Storing passwords in browser auto-fill without MFA
  - Using personal email passwords for work systems
