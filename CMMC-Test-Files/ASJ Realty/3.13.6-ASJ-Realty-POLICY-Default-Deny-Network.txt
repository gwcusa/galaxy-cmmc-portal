SYSTEM AND COMMUNICATIONS PROTECTION POLICY
Organization: ASJ Realty
Control: 3.13.6 - Default-Deny Network Communications
Version: 1.2  |  Effective: 2026-01-15
Owner: Sandra Okonkwo, IT Director  |  Approved: Anthony James, Office Manager

1. PURPOSE
This policy requires ASJ Realty to deny network communications traffic by default and allow only by exception, per NIST SP 800-171 Rev. 2 control 3.13.6.

2. SCOPE
All ASJ Realty firewall and network access control configurations.

3. REQUIREMENTS
a. All firewall and network ACL default rules are DENY ALL.
b. Specific allow rules must be documented and approved before implementation.
c. Allow exceptions are reviewed quarterly and removed when no longer needed.
d. Sandra Okonkwo can demonstrate default-deny posture through firewall rule listing.
e. Any traffic not matching an explicit allow rule is blocked and logged.

4. RESPONSIBILITY
Sandra Okonkwo, IT Director, configures and maintains default-deny network posture.

5. ENFORCEMENT
Any firewall configuration allowing traffic by default is a critical finding.

Signed: Anthony James, Office Manager  |  ASJ Realty  |  2026-01-15
