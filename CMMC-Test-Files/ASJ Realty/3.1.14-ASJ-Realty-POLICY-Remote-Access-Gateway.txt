ACCESS CONTROL POLICY
Organization: ASJ Realty
Control: 3.1.14 - Managed Access Control Points for Remote Access
Version: 1.2  |  Effective: 2026-01-15
Owner: Sandra Okonkwo, IT Director  |  Approved: Anthony James, Office Manager

1. PURPOSE
This policy requires ASJ Realty to route all remote access through managed access control points, per NIST SP 800-171 Rev. 2 control 3.1.14.

2. SCOPE
All remote access to ASJ Realty CUI systems and networks.

3. REQUIREMENTS
a. All remote access is routed through a centrally managed VPN gateway.
b. Split tunneling is disabled; all traffic routes through ASJ Realty gateway.
c. Direct internet access to internal CUI systems from outside the VPN is blocked.
d. The VPN gateway is managed exclusively by Sandra Okonkwo.
e. Firewall rules enforce that CUI systems are reachable only via VPN.

4. RESPONSIBILITY
Sandra Okonkwo, IT Director, maintains the VPN gateway and access control infrastructure.

5. ENFORCEMENT
Attempts to bypass the managed access point are security incidents.

Signed: Anthony James, Office Manager  |  ASJ Realty  |  2026-01-15
