SYSTEM AND COMMUNICATIONS PROTECTION POLICY
Organization: ASJ Realty
Control: 3.13.2 - Security Architecture
Version: 1.2  |  Effective: 2026-01-15
Owner: Sandra Okonkwo, IT Director  |  Approved: Anthony James, Office Manager

1. PURPOSE
This policy requires ASJ Realty to employ architectural designs, software development techniques, and systems engineering principles that promote security as part of the CUI environment, per NIST SP 800-171 Rev. 2 control 3.13.2.

2. SCOPE
All ASJ Realty system design decisions affecting CUI systems.

3. REQUIREMENTS
a. CUI systems follow a defense-in-depth architecture.
b. Security is considered from the initial design phase of any new system.
c. The CUI environment architecture is documented and maintained.
d. Vendor solutions are evaluated for security before deployment.
e. Security architecture is reviewed annually or after significant changes.

4. RESPONSIBILITY
Sandra Okonkwo, IT Director, designs and documents CUI system architecture with security as a core principle.

5. ENFORCEMENT
New systems without security architecture review may not process CUI.

Signed: Anthony James, Office Manager  |  ASJ Realty  |  2026-01-15
