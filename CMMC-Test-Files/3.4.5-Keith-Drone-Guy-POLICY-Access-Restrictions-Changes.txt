CONFIGURATION MANAGEMENT POLICY
Organization: Keith the Drone Guy LLC
Control: 3.4.5 - Access Restrictions for Configuration Changes
Version: 1.2  |  Effective: 2026-01-15
Owner: Keith Merritt, Owner-Operator  |  Approved: Keith Merritt, Owner-Operator

1. PURPOSE
This policy defines and enforces access restrictions associated with Keith the Drone Guy LLC configuration changes, per NIST SP 800-171 Rev. 2 control 3.4.5.

2. SCOPE
All Keith the Drone Guy LLC CUI systems and their configuration management functions.

3. REQUIREMENTS
a. Only Keith Merritt is authorized to implement configuration changes on CUI systems.
b. Physical access to server rooms and network equipment requires key card authorization.
c. Remote configuration changes require VPN and MFA authentication.
d. Configuration management tools are accessible only to Keith Merritt.
e. Attempts by unauthorized users to make configuration changes are detected and alerted.

4. RESPONSIBILITY
Keith Merritt, Owner-Operator, implements and enforces access restrictions for system configuration.

5. ENFORCEMENT
Unauthorized configuration changes are treated as security incidents.

Signed: Keith Merritt, Owner-Operator  |  Keith the Drone Guy LLC  |  2026-01-15
