CONFIGURATION MANAGEMENT POLICY
Organization: Money Straight Talk LLC
Control: 3.4.8 - Application Allowlisting
Version: 1.2  |  Effective: 2026-01-15
Owner: Terrell Banks, Systems Admin  |  Approved: Camille Odom, CEO

1. PURPOSE
This policy requires Money Straight Talk LLC to apply deny-by-default and allow-by-exception policies to prevent use of unauthorized software, per NIST SP 800-171 Rev. 2 control 3.4.8.

2. SCOPE
All Money Straight Talk LLC CUI endpoints and servers.

3. REQUIREMENTS
a. Only approved applications may execute on CUI endpoints.
b. Application allowlisting is enforced via Windows Defender Application Control (WDAC).
c. All new software requests require review and approval by Terrell Banks and Camille Odom.
d. The approved application list is reviewed and updated quarterly.
e. Attempts to execute unapproved software generate security alerts.

4. RESPONSIBILITY
Terrell Banks, Systems Admin, creates and maintains the application allowlist and WDAC policy.

5. ENFORCEMENT
Execution of unapproved software is blocked automatically and generates an alert.

Signed: Camille Odom, CEO  |  Money Straight Talk LLC  |  2026-01-15
