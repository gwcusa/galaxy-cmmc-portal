ACCESS CONTROL POLICY
Organization: Money Straight Talk LLC
Control: 3.1.14 - Managed Access Control Points for Remote Access
Version: 1.2  |  Effective: 2026-01-15
Owner: Terrell Banks, Systems Admin  |  Approved: Camille Odom, CEO

1. PURPOSE
This policy requires Money Straight Talk LLC to route all remote access through managed access control points, per NIST SP 800-171 Rev. 2 control 3.1.14.

2. SCOPE
All remote access to Money Straight Talk LLC CUI systems and networks.

3. REQUIREMENTS
a. All remote access is routed through a centrally managed VPN gateway.
b. Split tunneling is disabled; all traffic routes through Money Straight Talk LLC gateway.
c. Direct internet access to internal CUI systems from outside the VPN is blocked.
d. The VPN gateway is managed exclusively by Terrell Banks.
e. Firewall rules enforce that CUI systems are reachable only via VPN.

4. RESPONSIBILITY
Terrell Banks, Systems Admin, maintains the VPN gateway and access control infrastructure.

5. ENFORCEMENT
Attempts to bypass the managed access point are security incidents.

Signed: Camille Odom, CEO  |  Money Straight Talk LLC  |  2026-01-15
