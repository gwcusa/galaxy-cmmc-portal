CONFIGURATION MANAGEMENT POLICY
Organization: Bumpass Fire & Rescue
Control: 3.4.5 - Access Restrictions for Configuration Changes
Version: 1.2  |  Effective: 2026-01-15
Owner: Mike Sadler, IT Coordinator  |  Approved: Randy Bowles, Fire Chief

1. PURPOSE
This policy defines and enforces access restrictions associated with Bumpass Fire & Rescue configuration changes, per NIST SP 800-171 Rev. 2 control 3.4.5.

2. SCOPE
All Bumpass Fire & Rescue CUI systems and their configuration management functions.

3. REQUIREMENTS
a. Only Mike Sadler is authorized to implement configuration changes on CUI systems.
b. Physical access to server rooms and network equipment requires key card authorization.
c. Remote configuration changes require VPN and MFA authentication.
d. Configuration management tools are accessible only to Mike Sadler.
e. Attempts by unauthorized users to make configuration changes are detected and alerted.

4. RESPONSIBILITY
Mike Sadler, IT Coordinator, implements and enforces access restrictions for system configuration.

5. ENFORCEMENT
Unauthorized configuration changes are treated as security incidents.

Signed: Randy Bowles, Fire Chief  |  Bumpass Fire & Rescue  |  2026-01-15
