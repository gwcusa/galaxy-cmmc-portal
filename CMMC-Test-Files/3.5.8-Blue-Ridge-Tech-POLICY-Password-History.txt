1. PURPOSE
This policy prohibits the reuse of previous passwords to
ensure that users cannot cycle back to compromised credentials.

2. PASSWORD HISTORY REQUIREMENTS

2.1 Active Directory Domain Accounts
  - Password history enforced: last 12 passwords
  - Users cannot reuse any of their previous 12 passwords
  - Enforced via Active Directory Fine-Grained Password Policy
    and Default Domain Policy

2.2 Azure AD / Microsoft 365
  - Azure AD enforces 12-password history for cloud-only
    accounts (Password Hash Sync users inherit AD policy)
  - Password protection enabled: blocks common passwords
    and BRTS-specific banned terms

2.3 Local Accounts
  - Local administrator accounts also subject to 12-password
    history (enforced via GPO)
  - LAPS (Local Administrator Password Solution) manages local
    admin passwords automatically with unique, rotating values

3. PASSWORD CHANGE INTERVAL
  - Minimum password age: 1 day (prevents rapid cycling)
  - Maximum password age: 365 days
  - Users are prompted to change password 14 days before expiry

4. MONITORING
  Nathan Cruz confirms password history settings quarterly
  using Get-ADDefaultDomainPasswordPolicy and LAPS reports.
