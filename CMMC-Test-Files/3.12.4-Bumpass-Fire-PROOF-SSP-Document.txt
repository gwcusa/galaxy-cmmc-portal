SECTION 2 — SYSTEM DESCRIPTION
-------------------------------------------------
Bumpass Fire & Rescue operates a small-scale IT environment
supporting emergency dispatch, personnel records, and
federal grant administration. CUI handled includes federal
grant recipient data, personnel background check results,
and DHS/FEMA program records.

Primary components:
  - 1x Windows Server 2022 (file server + domain controller)
  - 7x Windows 11 workstations
  - CAD software: ESO Fire (cloud-hosted, vendor-managed)
  - Microsoft 365 Business Premium (email, SharePoint, Teams)
  - Meraki MX67 Firewall/VPN
  - Grant Portal: FEMA Grants Outcomes (GO) — web browser access

SECTION 3 — SYSTEM BOUNDARY
-------------------------------------------------
In-scope systems: All systems listed in Section 2
Out of scope: Personal devices not enrolled in MDM
External connections: FEMA GO portal (HTTPS only), ESO Fire (HTTPS)
Network: 192.168.50.0/24 (internal LAN), VPN (10.10.1.0/24)
